# PDFs Folder

Place your PDF files here for the chatbot to read and answer questions about.

## Instructions:

1. Add one or more PDF files to this folder
2. Restart the application by running: `chainlit run app.py`
3. Start chatting with your PDFs!

The app will automatically:
- Load all PDF files from this folder
- Extract and process the text
- Create a searchable database
- Allow you to ask questions about the content

## Supported:
- Multiple PDF files
- Multi-page PDFs
- Text-based PDFs (not scanned images)

## Tips:
- Give your PDF files descriptive names
- The app will show which file the answer came from
- You can add or remove files and restart the app anytime
